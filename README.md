IPL 2018 &amp; 2019 player performance analysis using SQL and Google BigQuery, exploring batting, bowling, strike rates, boundaries, and data-driven insights. 
🏏 IPL 2018–2019 | SQL Player Performance Analysis

By Tina Das | Aspiring Data Analyst

📌 Project Overview
This project explores IPL player performance using SQL queries executed in Google BigQuery. The analysis focuses on batting runs, strike rates, boundaries, half-centuries, wickets and bowling economy rates using exported query results.

🛠️ Tools & Technologies
- Google BigQuery
- SQL
- CSV datasets
- Data visualization and analytical storytelling

🎯 Project Objectives
- Identify leading run scorers and wicket takers.
- Compare batting strike rates and boundary counts.
- Examine bowling economy and wicket-taking performance.
- Communicate meaningful insights with visualizations.
- Validate data coverage and recognize limitations.

📊 Key Findings

1. Top Run Scorers — 2018
Kane Williamson leads the supplied 2018 run-scoring export with 735 runs, followed by Rishabh Pant with 684 and KL Rahul with 659.

2. Batting Strike Rate
Rishabh Pant has the highest strike rate among the ten listed batters at 173.60.

3. Boundary Analysis
Rishabh Pant leads the supplied boundary-count results with 105 boundaries: 68 fours and 37 sixes.

4. Fours — 2019
Shikhar Dhawan leads the supplied 2019 fours export with 64, followed by David Warner with 57.

5. Wicket-Taking Performance
Andrew Tye leads the 2018 wicket export with 24 wickets. Rashid Khan and Siddarth Kaul follow with 21 each.

6. Bowling Economy
Ish Sodhi records an economy rate of 5.87 in the supplied subset, while Rashid Khan combines 21 wickets with a 6.74 economy rate.

7. Half-Centuries
KL Rahul leads the supplied half-century count with 12.

🔎 Data Quality & Limitations
The supplied CSV exports do not all identify their season. The 2018 and 2019 wicket exports contain identical results, so a reliable year-over-year bowling comparison cannot yet be made. Match-level, team, toss and venue analysis requires additional data.

💻 SQL Skills Demonstrated
- Data filtering with WHERE
- Aggregation using SUM and COUNT
- Grouping with GROUP BY
- Sorting using ORDER BY
- Combining multiple datasets using UNION ALL
- Comparative player analysis
- Query result validation
